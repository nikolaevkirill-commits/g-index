Політика конфіденційності NeboRhythm

Оновлено: 15 вересня 2026 року.

NeboRhythm використовує прогнозний механізм G-Index і є advisory/reflective planning інструментом у процесі prospective validation. Він не надає медичних, фінансових або юридичних порад.

Які дані можуть оброблятися

  • Email, ідентифікатор користувача та сесія — для реєстрації, входу і відновлення доступу.
  • Push endpoint і криптографічні ключі підписки — лише після дозволу на сповіщення.
  • Дані профілю та налаштування — для персонального контексту; частина зберігається локально у браузері.
  • Добровільні записи outcome/decision journal — лише коли користувач їх створює.

Мета й передача

Дані використовуються для роботи функцій, безпеки, підтримки та перевірки якості. Ми не продаємо персональні дані. Мережевий обмін здійснюється через HTTPS; auth і push можуть оброблятися Cloudflare Worker/D1.

Версія Google Play

У режимі Google Play реєстрація, вхід і мережеві запити підписки на push вимкнені. Наведений вище опис цих функцій стосується вебверсії, де вони доступні. Локальний журнал подій інтерфейсу зберігається у сховищі браузера; його поточна реалізація не надсилає ці події аналітичному сервісу.

Хостинг і зовнішні джерела

Для завантаження застосунку й оновлення даних пристрій звертається до GitHub Pages та зовнішніх джерел. GitHub Pages зберігає IP-адреси відвідувачів для безпеки, зокрема без входу в GitHub. Докладніше: обробка даних у GitHub Pages та політика GitHub.

Запити до джерел космічної погоди можуть виконуватися прямо або через Cloudflare Worker і резервні CORS-проксі. Проксі отримує адресу запитуваного ресурсу; залучені мережеві сервіси отримують IP-адресу та технічні відомості HTTP-запиту. Їхня обробка регулюється політиками відповідних сервісів, зокрема політикою Cloudflare. Вимкнення входу й push у Play-версії не усуває ці мережеві звернення.

У Play-режимі резервні маршрути через AllOrigins і CodeTabs вимкнені. Для інших резервних маршрутів діють політика CorsProxy та політика Corsfix. Бібліотека Excel постачається разом із застосунком через GitHub Pages; окремого запиту до CDN для її завантаження немає. Ці сервіси можуть обробляти IP-адреси, відомості браузера, технічні ідентифікатори, адреси запитів і діагностику для надання сервісу, аналізу його роботи та безпеки. Це не передача вмісту локального Excel-файлу: його обробляє бібліотека на пристрої.

Прямі джерела космічної погоди: NOAA SWPC (services.swpc.noaa.gov), GFZ (kp.gfz.de), SILSO/SIDC (sidc.be, www.sidc.be) та Geophysical Institute, University of Alaska Fairbanks (www.gi.alaska.edu). Вони отримують технічні дані відповідного HTTP-запиту. Для календарних довідок також використовуються www.timeanddate.com, www.vaisnavacalendar.info та ics.calendarlabs.com. Завантажений Excel обробляється локально; його вміст не додається до запитів погодних джерел.

Контроль користувача

Push можна вимкнути, локальні дані — очистити в налаштуваннях браузера, а акаунт і пов'язані серверні дані — попросити видалити на окремій сторінці.
