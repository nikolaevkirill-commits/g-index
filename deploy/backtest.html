v18.7 → v18.8 Real Bug Fix Story

Trigger: Production scan на 2026-05-11 показав engine pill +2 ★ (з expert override), але raw engine score = -3. Investigation tag = "⚡ ✈ ⊕" — НЕ "Подорожі✈".

Root cause: v18.7 P2 patch перевіряв tag.contains("Подорожі") — case-sensitive word match. Реальні engine_scores використовують 3 patterns:

  • "Подорожі✈" — Capital + emoji (24 dates) ✓ caught
  • "подорожі✈" — lowercase + emoji (~65 dates) ✗ MISSED
  • "⚡ ✈ ⊕" — emoji-only (~28 dates) ✗ MISSED

Same time: P3 patch був тільки на Shukla Dashami (Tithi 10) — пропускав Krishna Dashami (Tithi 25), хоча обидва — "Пурна" тип за Posibnyk Тaблицею 1.

Fix: v18.8 розширює P2 на ANY ✈ emoji (з differentiated boost: word+emoji = strong, emoji-alone = mild). P3 розширений на обидва Dashami values.

Validation: +1.8pp strict, +0.9pp exact, CV stability improved.

Methodology

Strict 3-class agreement: Engine sign (-1/0/+1) equals expert sign on the same date.

Binary neg/non-neg: Engine and expert both classify day as <0 (negative) or ≥0 (non-negative).

ExactMatch: Engine integer score (-3..+3) equals expert integer score exactly.

Engine output: Discrete integer score on 7-class scale [-3, +3] per day. Dashboard raw context uses G_raw = 2 − Kp + ΣAᵢ, where ΣAᵢ = Lᵢ + Mᵢ + eᵢ + Pᵢ + Dᵢ; the frozen Engine itself remains a threshold classifier.

v18.8 patches: Applied at READ TIME у JS function _applyV186Patches(). Frozen engine_scores.json файл НЕ модифікується. Phase V3 freeze respected (md5 unchanged).

Ground truth (v5.1): 329 unique dates extracted from 47-page expert PDF bulletin (Jun 2025 → May 2026). 22 textual pages parsed directly + 25 image pages via vision OCR. 12 multi-source inconsistencies reconciled by median rule. Filter n=212 — dates with available PDF reference (excluding gaps, current weeks).

Cross-implementation consistency: JS (_applyV186Patches) + Python tracker + Python DOCX gen — все три implementations sync на 564/564 dates (0 desync).

⚠ Critical: what this validation does NOT show. Ground truth є expert PDF bulletins що використовують саме той Vedic Panchanga + Kp framework що й engine. Висока згода (κ=0.73 weighted на v5.1 baseline) демонструє що engine надійно reproduces expert reasoning. Це не демонструє що underlying framework predicts real-world outcomes (medical events, operational incidents, financial movements). Outcome-based validation проти independent event records ще не проведена. Prospective validation period (90 days from 2026-05-03) у процесі і закриється ~2026-08-01. До того часу — treat усі metrics as in-sample/retrospective.
