      ℹ Як читати індекс G

      G показує, наскільки «легкий» чи «важкий» сьогоднішній день з точки зору космічної погоди та хронобіології. Значення вище нуля — відносно легкий день; нижче нуля — підвищене невидиме навантаження.

      Кольори шкали від 🟢 до 🔴 допомагають швидко оцінити стан: зелений — сприятливий фон, жовтий/помаранчевий — варто бути обережнішим, червоний — максимальне зовнішнє навантаження.

      2−Kp — це геомагнітна частина (космічна погода). ΣAᵢ — хронобіологічна (Місяць, затемнення, свята, Панчанга). Разом вони дають G.

      Чому на екрані кілька різних чисел

      Оперативний стан (шкала −3…+3) — головна команда зараз. Він обирає обережніший результат, якщо джерела конфліктують.

      PDF/Engine reference — заморожений денний сигнал для перевірки методики, не автоматичний дозвіл на дію.

      G_now / G_day raw — поточний або прогнозний фон з Kp та ΣAᵢ. Він лишається видимим як вхід оперативного safety-контуру.

      Якщо числа різняться знаком або сильною дельтою, дашборд має показати «конфлікт/пауза», а не називати один із сигналів фінальним рішенням.

      Формула G

      G = 2 − Kp + ΣAᵢ, де геомагнітна складова 2 − Kp дорівнює нулю при Kp = 2. Повний G тоді дорівнює ΣAᵢ, а не обов’язково нулю. Це авторський дослідницький індекс, не фізична одиниця й не ймовірність результату дня.

      Kp та Ap

      Kp — стандартний 3‑годинний глобальний індекс збурень магнітного поля Землі (діапазон 0–9), чутливий до пікових подій. Ap — пов'язаний добовий лінійний індекс: кожен 3‑годинний Kp конвертується в лінійний a‑індекс за офіційною табличною конверсією Kp→ap (GFZ/NOAA), після чого Ap обчислюється як середнє восьми a‑значень за добу.

      Оперативний 3‑добовий продукт NOAA SWPC надає прогноз Kp (8 трьохгодинних слотів на добу) та оцінку добового Ap на найближчі 3 доби. 27‑добовий продукт (27-Day Outlook) містить прогноз добового Ap, Kp max і F10.7 на ~1 місяць, що відображає обертальний цикл Сонця (~27 діб) і пов'язані магнітні структури. Відмінності між секціями дашборду природні: Kp відображає пікові 3‑годинні збурення, Ap — усереднений добовий фон.

      Для горизонту 27 днів модель бере Largest Kp напряму з NOAA 27-Day Outlook (6-те поле в `27-day-outlook.txt`) — без жодних перетворень. У fallback-режимі (NOAA 27-day недоступний → переходимо на 45-day-forecast.json) застосовується внутрішня дискретна апроксимація Ap→Kp за табличними порогами NOAA (VLOOKUP-стиль, найближчий нижчий поріг). Це не офіційний зворотний стандарт NOAA, а робоче припущення моделі; G-значення з fallback-режиму слід інтерпретувати як якісний індикатор тренду, а не точний 3-годинний прогноз.

      Склад ΣAᵢ

      ΣAᵢ = Lᵢ + Mᵢ + eᵢ + Pᵢ + Dᵢ

      Компонент Що враховує Діапазон
      LᵢАвторська вага тітхі: Амавасья = −3; Пурніма = −2 при Kp≥7, −1 при 5≤Kp<7, інакше 0; решта = 0. Прогностична користь цих ваг не підтверджена.−3 … 0
      MᵢАвторська вага затемнення залежить від типу (ECLIPSE_WEIGHT); ±1 день — trunc(0.75 × вага), ±2–3 дні — −1, поза вікном — 0. Відсутність каталогу також дає 0 з повідомленням про недоступність; це не доказ відсутності затемнення.−4 … 0
      eᵢСума авторських ваг ICS та автоматично доданих подій, зокрема сезонного терма Russell–McPherron. Фізична сезонність сама не підтверджує числову вагу в G.≈ −6 … +5
      PᵢPCL v4.0: PCL_SCALE × (Tithi×lunar_mod + Vara + Nakshatra + Yoga + Karana) — авторські числові ваги традиційних категорій Панчанги; lunar_mod = sin²(φ/2) застосовується лише до Tithi. Це дослідницька гіпотеза; Cajochen 2013 не калібрує цю функцію. PCL_SCALE = 0.4 збережено, оптимальність для чинної формули не доведена.≈ −4.4 … +3.6
      DᵢЛише для поточної дати за todayKyivStr(): Dst≤−100 нТл → −2; −100<Dst≤−50 → −1; інакше 0. Недоступний Dst → 0 з позначкою недоступності; для інших дат → 0, це не прогноз Dst.−2 … 0

      Kp ∈ [0; 9]. Раніше наведені межі ΣAᵢ [−10; +9] і робочі ΣAᵢ ≈ −4 … +4 не мають тут відтворюваного підтвердження. За першого припущення формула дає умовний інтервал G ∈ [−17; +11], а не старий [−12; +16]. Досяжність крайніх значень і старий робочий G ≈ −5 … +7 не встановлені; приблизні діапазони компонентів не є гарантією.

      Множник PCL_SCALE = 0.4 для Pᵢ має статус R&D / Advisory і потребує емпіричного калібрування на операційних даних. Історичний PCL_CALIBRATION_REPORT використовував Kp − 2 та спрощений Pi без lunar_mod, тому не валідує чинну формулу. Специфікація, докази та обмеження методики.

      Категорії G‑індексу (discrete, engine v18.5 pill)

      Назви категорій та наведені інтерпретації — авторська шкала. Вони не є підтвердженим прогнозом здоров’я, безпеки чи успішності дії.

      Hero G — continuous score (raw composite). Engine pill і ця табличка — discrete classifier {−3..+3}. Boundary regions у Hero (continuous): G≥+1.5 favorable; +0.5..+1.5 good; −1..+0.5 neutral; −2.5..−1 unstable; ≤−2.5 tense.

      G Категорія Інтерпретація
      ≥ +2🟢 Особливо сприятливийМінімальні збурення + позитивні фактори; оптимально для активних рішень
      +1🟢 Помірно сприятливийФон у межах норми, допустимо для планових операцій
      0⚪ НейтральнийБаланс факторів; стандартний оперативний режим
      −1🟡 Помірно несприятливийСлабке підвищення навантаження; обережність у чутливих операціях
      −2🟠 НесприятливийПідвищене навантаження на адаптаційні системи; мінімізувати ризики
      ≤ −3🔴 Особливо несприятливийСильні збурення + негативні фактори; утриматись від критичних рішень

      При Kp ≥ 5 (геомагнітна буря G1+) дашборд показує попередження незалежно від значення G, оскільки буря сама по собі є значущим фактором ризику.

      У день Амавасьї Lᵢ = −3. При Kp = 2 і нульових інших компонентах G = −3; інші доданки можуть змінити результат, тому загальна заборона G = 0 математично неправильна.

      Схема формули G-індексу

      G = (2 − Kp) + Lᵢ + Mᵢ + eᵢ + Pᵢ + Dᵢ. Sn/Wolf показується як контекст із score_effect=0. Статистична незалежність компонентів не встановлена. Bz/Vsw, Hora та Sn — інформаційний контекст поза сумою.

      Цикл Taara — 9 позицій

      Позиція = (поточна Накшатра − натальна) mod 27, потім mod 9. У традиційній інтерпретації парні + 9 називають сприятливими, 1,3,5,7 — несприятливими; фактичну небезпеку це не встановлює.

      Hora — планетарні години

      День від сходу до заходу та ніч діляться окремо на 12 Хор; їх тривалість залежить від довжини дня й ночі, не обов'язково 60 хв. Послідовність планет: ♄→♃→♂→☉→♀→☿→☽→♄… Перша Хора дня = планета-регент (Vara). Нижче — приклад для неділі (☉, схід 06:00 місц.).
