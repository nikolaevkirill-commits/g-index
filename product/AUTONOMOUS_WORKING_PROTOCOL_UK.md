# Протокол автономної роботи

Дата: 2026-08-12. Це робоче правило для продовження продуктового roadmap.

1. Якщо наступний безпечний крок уже визначений у затвердженому roadmap, робота продовжується автоматично.
2. Після завершення одного блоку агент сам переходить до наступного незакритого пункту.
3. Проміжний звіт не означає зупинку.
4. Зупинка допускається лише коли потрібні:
   - нова зовнішня авторизація;
   - платіж, публікація або незворотна дія;
   - вибір, який істотно змінює продукт і не випливає з канону;
   - відсутні дані, які неможливо безпечно отримати.
5. При вимушеній зупинці ставиться одне конкретне питання з поясненням, що саме воно розблокує.
6. Production dashboard, формула й GitHub не змінюються лише на підставі продуктового прототипу; для них діють окремі release gates.
7. v19.2 і Tanita не промоутяться автоматично та залишаються Shadow до prospective evidence.
