# Jyotish Personal — research engine

Модуль готує D1, D9, Lagna, whole-sign bhava, дев'ять graha та Vimshottari для незалежної перевірки. Він не активований у consumer UI і завжди повертає `score_effect: 0`.

Astronomy Engine 2.1.19 (MIT) використано для тропічних геоцентричних позицій. Lahiri ayanamsha та mean node зараз є research-апроксимаціями; це не Swiss Ephemeris.

Увімкнення заборонено до незалежної звірки 100 карт, boundary-тестів, editorial review та перевіреного локального privacy/export/delete flow. Swiss Ephemeris не включено: для закритого комерційного продукту потрібна Professional License, а без неї діє AGPL.
