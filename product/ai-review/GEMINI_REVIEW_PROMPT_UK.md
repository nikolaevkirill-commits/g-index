# Роль Gemini: конкурентний і культурно-мовний stress-test

Прочитай `PUBLIC_BRAND_BRIEF_UK.md`. Проведи критичний рев’ю українською.

1. Перевір, як назва сприймається українською, російською та латиницею `Neborytm`.
2. Визнач можливі небажані асоціації, плутанину й труднощі пошуку.
3. Порівняй позиціонування з класами aurora/space-weather, Panchang/Jyotish і wellness apps без вигаданих фактів.
4. Запропонуй 3 варіанти store title, short description і slogan.
5. Оціни, чи Панчанга має бути в першому повідомленні бренду.
6. Не пропонуй змін формули або заяв про точність.

Заверши матрицею: диференціація / зрозумілість / довіра / масштабованість, кожна 0–10.
