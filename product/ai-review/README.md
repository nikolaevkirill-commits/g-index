# Незалежне AI-рев’ю бренду

Ця папка налаштовує ролі Claude, Gemini й Copilot без доступу до production або приватних даних.

## Порядок

1. Передати кожному лише `PUBLIC_BRAND_BRIEF_UK.md` і його prompt.
2. Зберегти відповіді як `responses/<provider>-YYYY-MM-DD.md`.
3. Позначити твердження, які повторилися у двох або трьох незалежних рев’ю.
4. Не приймати назву автоматично: потрібні людське рішення та trademark/store clearance.

CLI/API не налаштовані без явної авторизації користувача. Допускається використання вже авторизованої веб-сесії, але без вставлення секретів або приватних матеріалів.
