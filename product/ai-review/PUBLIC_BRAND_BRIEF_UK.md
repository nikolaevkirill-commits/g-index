# Публічний бриф для незалежного AI-рев’ю

Продукт-кандидат: **Неборитм**.

Суть: мобільний пояснюваний планувальник дня. Показує один оперативний стан, космічну погоду, планетарні та місячні події, календарний контекст Панчанги, персональний ритм і походження даних. Не є медичною, фінансовою або гарантованою прогностичною системою.

Аудиторії:

- 18–35: швидкий висновок, сучасний візуал, мінімум термінів;
- 35–65+: чіткі пояснення, час даних, джерела та межі;
- професійні профілі: медик, пілот, трейдер, військовий — лише як режими відображення ризиків, не як професійна порада.

Ключові принципи:

- один головний стан;
- «Просто / Детально» не змінює результат;
- Панчанга — один складений календарний компонент;
- research/shadow не впливають на оцінку;
- колір джерела не дорівнює дозволу діяти.

Назва-кандидат: **Неборитм**.

Слоган-кандидат: **Небо. Час. Твій ритм.**

Категорія-кандидат: **Космічна погода, Панчанга і зрозумілий ритм дня.**

Візуал: темно-синє небо, бірюзові магнітні дуги, стримане Сонце, Місяць, Земля, орбіти та кілька впізнаваних планет, бурштинові акценти. Без літери G.

Обмеження рев’ю: не пропонувати зміни ваг, формули або прогнозу; не вигадувати точність; не просити персональні дані.
