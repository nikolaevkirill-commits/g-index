# Неборитм — продуктова специфікація

`G-Index` залишається технічною назвою наявного рушія та URL до завершення міграції.

## Призначення

Неборитм — пояснювана advisory-система для планування дня. Вона розділяє космічну погоду, календарний контекст Панчанги, персональний ритм та дослідницькі сигнали й не гарантує результат подій.

## Перший екран

1. Один оперативний стан: діяти, обережно або відкласти.
2. Коротка причина, свіжість і походження даних.
3. Найближча зміна або обмеження часу.
4. Кнопка «Чому така оцінка?» з внеском факторів.
5. Перемикач «Просто / Детально», який не змінює прогноз.

## Семантика кольорів

- зелений у рішенні — лише сприятливий оперативний стан;
- бірюзовий у джерелі — актуальність/доступність, не дозвіл діяти;
- жовтий — обережність або неповні дані;
- червоний — обмеження/стоп;
- синій/сірий — інформація, raw, reference чи shadow;
- фіолетовий — дослідницький Tanita/v19.2 без впливу на оцінку.

## Шари рішення

| Шар | Роль | Може змінити Hero |
|---|---|---|
| Operational resolver | live/stale/storm safety | так |
| PDF/Engine reference | перевірений денний reference | ні, показується окремо |
| G raw | безперервний фон | ні |
| Панчанга | один складений компонент і пояснення слотів | не другим голосом |
| Персональний цикл | локальний контекст профілю | не перекриває глобальний ризик |
| Tanita | незалежний image-shadow | ні, `score_effect=0` |
| v19.2 | prospective shadow | ні, HOLD |

## MVP Google Play

- Сьогодні, 3 дні, Kp-alert, коротка Панчанга, пояснення факторів, локальний профіль.
- TWA відкриває `/g-index/?channel=play` без web-продажів, auth і push до окремої policy/device QA.
- Технічні таблиці та Formula Audit знаходяться у розділі «Ще».

## Межі

Це не медична, фінансова чи юридична порада. Категорійні та персональні підказки — контекст планування, не гарантія.
