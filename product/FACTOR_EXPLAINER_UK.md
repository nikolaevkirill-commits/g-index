# Як Неборитм пояснює фактори

Кожен фактор має відповідати на чотири питання: **що це**, **які дані**, **як вплинув**, **чого з цього не можна висновувати**.

| Фактор | Просте пояснення | Роль у системі |
|---|---|---|
| Kp | Спостережувана або прогнозована геомагнітна активність | Фізичний live/forecast контекст; джерело і горизонт показуються окремо |
| Bz і сонячний вітер | Умови, що можуть посилити геомагнітну реакцію | Попереджувальний фізичний шар, не самостійний прогноз дня |
| Затемнення | Астрономічна подія і календарний контекст | Інформаційна подія; вплив на оцінку показується лише якщо вже є у замороженій формулі |
| Панчанга | Tithi, Vara, Nakshatra, Yoga, Karana та часові вікна | Один складений календарний компонент `P`, не п'ять додаткових голосів |
| Rahu/Yama/Gulika | Локальні часові вікна Панчанги | Обмеження конкретного слота, не автоматичний вирок усьому дню |
| Персональний цикл | Локальний шар для обраного профілю | Не перекриває глобальний оперативний ризик |
| PDF/Engine | Перевірений експертний денний reference | Показується окремо; не дорівнює live-дозволу діяти |
| Tanita | Незалежний дослідницький сигнал | Shadow, `score_effect=0` |
| v19.2 | Кандидат нової моделі | Shadow/HOLD до нових prospective observations |

## Канонічна картка «Чому така оцінка?»

1. **Рішення зараз:** діяти / обережно / відкласти.
2. **Головна причина:** один провідний фактор людською мовою.
3. **Фактори:** значення, знак внеску, час і джерело.
4. **Найближча зміна:** конкретний час або чесне «невідомо».
5. **Якість даних:** live, delayed, forecast, last-good або reference.
6. **Межа:** це контекст планування, не медична, фінансова чи юридична порада.

Колір джерела не означає «добре». Бірюзовий/зелений може позначати лише свіжість або доступність даних; дозвіл діяти визначає тільки оперативний стан.
